Credits & privacy

Your visit

This invitation has no analytics, advertising or guest login accounts. When shared leaderboards are connected, the invitation sends an anonymous browser identifier and round details to Cloudflare Workers and D1. Saving a result is optional: the nickname and best score you submit are visible to other guests. A random identifier is stored on this browser to keep your best results together; clearing browser storage creates a new identity. Games themselves keep their internal data in memory. Your hosting and database providers may maintain standard access logs.

RSVP details are used only to prepare a WhatsApp message. You review and send it in WhatsApp. Opening WhatsApp or Google Maps takes you to a third-party service governed by its own privacy policy.

Open-source games

Each game runs in a sandboxed frame with outbound network connections blocked. It reports round starts and completed scores to the invitation, which handles the shared leaderboard. Names are checked before being saved.

  • Tap Tap Tap — Mahdi Al-Farra. MIT license. Download modified source.
  • Safari Flyer (Floppy Bird adaptation) — original game code by Nebez Briefkani under Apache-2.0. Download modified source. New CSS artwork and text scores replace the original game images. No original Flappy Bird images or sounds are distributed.
  • Hextris — Logan Engstrom, Garrett Finucane, Noah Moroze, and Michael Yang. GPL-3.0-or-later license. Download complete modified source.
  • 0h h1 — Q42, created by Martin Kool. MIT license. Download complete modified source.

Invitation adaptations (September 2026): removed advertising, analytics, social promotions, and external scripts; replaced persistent storage with session memory; applied restrictive content policies; embedded fonts; replaced Hextris function deserialization with data-only JSON; replaced the 0h h1 dynamic script loader with static local scripts. Tap Tap Tap: analytics and audio removed, local styles, and pointer input adapted for touch. Safari Flyer: original CSS art, responsive play area, no audio or telemetry, local libraries and unified pointer controls. Round-completion hooks support shared leaderboards; 0h h1 ranks solve times separately by board size and excludes tutorials. The game mechanics remain upstream work. Legacy touch listeners are adapted for modern passive-event defaults. All original license notices are retained.
